Code bundle for "Diffusion-Purified Randomized Smoothing on CIFAR-10"
- certified_smoothing_kaggle_v2.ipynb : Kaggle notebook (setup, data, ResNet-20, diffusion purifier, CERTIFY, pilot seed run)
- drs_pipeline_extracted.py : same code cells as a plain .py file
- pilot notebooks : earlier versions
NOT included (not saved in this session): the final fine_tune_model(sigma, purified) cell, the resumable per-seed sigma-sweep cell, and the Lipschitz cell. Take these from your Kaggle notebook (Save Version / File > Download notebook).
